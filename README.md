
# LinkUp 

thank you for reading this readme \
a student made project

> **A community-based class tool** built to replace messy class links and chaotic group chats with one organized space for students.


## What's Inside
 Core Features:
- **Personalized Schedules:** There is now no more need to look through two document for the right link before class starts.
-  **Peer Notes & Recaps:** For catching up on what you missed with student-shared notes. Another feature correlates to this, so that is a students join class late there is a popup showcasing what the class did so far 
-  **Moderated Hangouts:** Group study rooms  chats and activity rooms to encourage studying
-  **Student Notice Board:** A shared space for class memories, achievements, goals, news, funny quotes , memes , posters and even a status feed for what people are up to 
-  **Safe and Bullying-proof** Just in case , some of the content users have intentions , the website has certain features designed to stop bots , bullying , hacking etc and all the things neccessary to cultivate a safe environment

-  __Community experience__:\
    Buzz — LinkUp's community activity terminology.
     Hives — the name for communities/groups.

 
  -  __What happens after a report__
This is more than just a report button.
     - Reports enter a review process rather than becoming public accusations.
     - Automated screening happens first.
     - An admin reviews flagged situations.
     - Possible actions include hiding content, issuing a warning, or restricting access.
     - The reporter can receive a private update about the report.
     - Reporting is designed not to require the student to confront the person themselves.

## Why linkup

The reason why Link up was made was because most kids in our class couldnt access the links which were shared to join class they  often came late and left the class early not understanding what they shouldve .
 Even though other students (including me) with access to the school timetable, were helpful enough to share the links and the documents the same problem kept on happening again 

soo...


>Linkup mostly started as a quick way to get into classes with an additional popup modal to get a quick recap on what you missed (basically a popup with notes on what the class was talking about)

___it started as a solution to a problem___

 but quickly became a more intuitive design and thence came forth version two which focuses on community and a place where students  can create the deciding factor to what makes studying more productive. 
 
 I want students to have the freedom to  answer that question and actually make their answer a reality
